# "点料表物料是否在三维体现"规则确认清单

依据客户纪要："点料表会大于等于三维的内容，后续不需要在三维体现的会标识出来，先学习、列出来确认、确认后保存。"

基于三个案例（8A/8B/海神）点料表 1872 条物料的类别分析，初步分为三类供确认：

## 一、应在三维体现（生成器件）
| 类别 | 匹配库型号率 | 说明 |
|------|------------|------|
| valve（阀门） | 18% | 气动/手动/隔膜/针/调压/安全/单向阀等。能匹配库型号的在三维放真实模型，未匹配的（如调压阀RC2000）需补器件库 |
| fitting（管件/接头） | 9% | 三通/弯头/大小头/堵头/穿板等。G2FA系列在三维体现，部分（SMC/SME卡套接头等）需补库 |

## 二、建议标识为"不进三维"（需您确认）
| 类别 | 样例物料 | 理由 |
|------|---------|------|
| accessory（气管/辅材） | 气管Φ4/Φ6/Φ8、波纹软管、泵气管 | 纪要明确"气管这些材料不会在三维体现" |
| other（杂项/耗材） | 滤芯、滤壳、介质标签、密封圈、防火泥 | 多为耗材/标识，无独立三维几何 |
| sensor（传感器仪表类，部分） | 压力表、压力传感器、判位传感器 | 部分仪表已通过PID组件体现，部分点位表独有不进三维 |

## 三、待定（特殊处理）
| 类别 | 说明 |
|------|------|
| shell（壳体） | 壳体应作为三维基础机身生成（当前该类别匹配库为0，因为壳体用壳身生成逻辑而非库型号）。**建议：壳体计入三维，但用壳身生成器而非器件库** |
| pipe（管道） | 管道用管路生成器按拓扑生成，不靠库型号。**建议：计入三维（作为管路），但不走器件库型号匹配** |
| sensor（仪表在主PID上） | 已出现在PID组件中的仪表应进三维；点料表独有仪表可不进 |

## 请确认
1. 上述"二、建议不进三维"（气管/辅材/耗材/杂项）是否确认不进三维？
2. "三、待定"中 shell/pipe 是否都计入三维？
3. 是否还有其它您知道明确"不进三维"的物料类型关键词（例如：垫片、螺栓、标签、接线、标识牌等）？

确认后，我将把这些规则保存为一个"不参与三维生成物料规则"文件，生成时自动跳过并列出。
